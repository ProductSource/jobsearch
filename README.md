# BoolJobs

Next.js (App Router, TypeScript) app. Enter a role and a time window; get a Boolean search per applicant tracking system, career-page pattern and job board. Click a source to open it, tick it when you finish applying there.

Only the filters you set appear in the query. Visible: work arrangement, location, seniority. Under "More filters": salary, must include, exclude.

    npm install
    npm run dev      # http://localhost:3300
    npm run build

Deploy to Vercel: import the folder (framework preset "Next.js"). No environment variables needed.
